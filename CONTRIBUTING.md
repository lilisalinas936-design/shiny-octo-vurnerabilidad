# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto de investigación sobre ciberseguridad! Tu participación es valiosa para educar y prevenir ataques cibernéticos.

## 📋 Antes de Contribuir

Por favor, lee completamente nuestro [Código de Conducta](./CODE_OF_CONDUCT.md) y nuestra [Política de Seguridad](./SECURITY.md). Ambos documentos son fundamentales para mantener un ambiente seguro y respetuoso.

---

## 🔒 Principios Fundamentales

Este es un proyecto de investigación responsable. Al contribuir, te comprometes a:

1. **No revelar detalles técnicos específicos** que puedan facilitar replicas de ataques
2. **Proteger la privacidad** de las víctimas y las investigaciones en curso
3. **Mantener la ética** en la documentación de vulnerabilidades
4. **Colaborar responsablemente** con profesionales de seguridad
5. **Respetar las leyes** de ciberseguridad y privacidad

---

## 📝 Tipos de Contribuciones Bienvenidas

### ✅ Contribuciones Aprobadas

- 📚 **Documentación educativa**: Guías sobre protección y prevención
- 🛡️ **Mejoras de seguridad**: Sugerencias para sistemas más seguros
- 📖 **Recursos de aprendizaje**: Enlaces a cursos y materiales educativos
- 🐛 **Reportes de errores**: Problemas en documentación o código
- 💡 **Mejoras generales**: Claridad, estructura y accesibilidad
- 🌐 **Traducciones**: Hacer el contenido accesible en otros idiomas
- 🔍 **Investigación responsable**: Análisis de patrones de ataque sin detalles técnicos

### ❌ Contribuciones NO Permitidas

- 🚫 Herramientas o código para ejecutar ataques
- 🚫 Detalles técnicos específicos de exploits
- 🚫 Información de investigaciones activas o confidenciales
- 🚫 Datos personales de víctimas o atacantes
- 🚫 Contenido que incite a actividades ilegales
- 🚫 Spam o contenido irrelevante

## 🔄 Proceso de Contribución

### Paso 1: Abre un Issue
Antes de enviar un pull request, abre un **issue** describiendo tu propuesta.

### Paso 2: Espera Aprobación
El equipo revisará tu propuesta y dará feedback.

### Paso 3: Crea una Rama
```bash
git checkout main
git pull origin main
git checkout -b feature/tu-contribucion
```

### Paso 4: Realiza tus Cambios
- Sigue el formato de documentos existentes
- Usa Markdown
- Incluye referencias y fuentes
- Revisa ortografía

### Paso 5: Envía un Pull Request
Describe claramente qué cambios hiciste y por qué son valiosos.

### Paso 6: Revisión
Un mantenedor revisará tu PR. Una vez aprobado, se fusionará.
